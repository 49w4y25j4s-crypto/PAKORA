PAKORA – Telefon uygulaması dosyaları

Bu klasör, kurulabilir bir PWA (Progressive Web App) projesidir.

iPhone'a uygulama gibi yüklemek:
1. Bu klasörü HTTPS destekleyen bir statik web barındırma hizmetine yükleyin (ör. Netlify veya GitHub Pages).
2. Oluşan HTTPS adresini iPhone Safari'de açın.
3. Paylaş > Ana Ekrana Ekle > Ekle adımlarını izleyin.

Android:
1. HTTPS adresini Chrome'da açın.
2. Menü > Uygulamayı yükle / Ana ekrana ekle.

Önemli:
- PWA kurulumu için HTTPS gerekir; ZIP dosyasına dokunarak doğrudan App Store uygulaması kurulmaz.
- Görevler, finans bilgileri ve notlar cihazın tarayıcı depolamasında tutulur.
- İki ortağın aynı veriyi eşzamanlı görmesi için ayrıca çevrimiçi veritabanı ve kullanıcı girişi eklenmelidir.
- Yedek dosyası düğmesi JSON yedeği indirir.
